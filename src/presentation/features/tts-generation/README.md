# TTS Generation Feature

This feature handles the core functionality of generating text-to-speech audio from user input.

## Components

- **EditorComponent**: Text input and generation controls
- **AudioPlayerComponent**: Audio playback for generated speech

## Services

- **TTSGenerationManagerService**: Manages the TTS generation workflow
- **SettingsIntegrationManagerService**: Handles settings for generation
- **HistoryInteractionManagerService**: Manages history interaction with generated audio

## Responsibilities

- Text input and validation
- API key management
- TTS settings configuration
- Generation process management
- Audio playback control
- Storage management and warnings
- Error handling for generation process
